Painel independente de apoio à escolha de periódicos. Para publicar o site, abra **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.

**Importante:** o catálogo inicial é ilustrativo e nenhuma APC para UNEMAT é considerada confirmada. Os dados importados por CSV ficam armazenados somente no navegador do pesquisador, não no repositório. Indicadores devem ser consultados por ano, área e base.
